# Hero Images for RNP Traffic Homepage

Place the following Rwanda images in this folder:

1. **traffic-police-kigali.jpg** - Traffic police managing traffic at bus lane
2. **kigali-night-traffic.jpg** - Night traffic scene in Kigali city
3. **road-accident.jpg** - Truck accident on Rwanda road
4. **bus-accident-response.jpg** - Bus accident with firefighters/emergency response
5. **rnp-fire-brigade.jpg** - Rwanda National Police Fire Brigade team
6. **firefighter-action.jpg** - Rwanda Police firefighter in action fighting fire

## Image Requirements
- Recommended size: 1920x1080 pixels or larger
- Format: JPG or PNG
- These images will be displayed as full-screen hero backgrounds

## Current Slides Configuration
The homepage will rotate through these 6 images every 5 seconds.
